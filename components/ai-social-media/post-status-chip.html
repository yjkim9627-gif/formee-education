Post Status Chip

Figma: "06 Data Display" (8350:237808) → "Data / Post Status Chip" — a compact row of the platform icons a post went out to (Library/Schedule list rows). Each platform is its own boolean, so a row only shows the icons for platforms it actually published to. The 4 "Status" variants (Posted/Status2/Status3/Status4) render pixel-identical in Figma, so only one look is implemented here.
