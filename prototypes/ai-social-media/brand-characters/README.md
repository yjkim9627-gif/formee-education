# Brand Setup · Brand Kit · Character Library

AI Social Media 제품의 브랜드/캐릭터 영역 프로토타입입니다.
`brand-setup-kit-character-library.html` 한 파일에 세 영역이 들어 있고,
좌측 네비게이션으로 이동합니다.

| 영역 | 진입 | 내용 |
|---|---|---|
| Brand Setup | 좌측 `Brand Setup` | 브랜드 목록 · 브랜드 워크스페이스 |
| Brand Kit | Brand Setup → 브랜드 카드 → `Brand Kit` 탭 | Overview / Logos / Colours / Fonts / Graphics / Photos |
| Character Library | 좌측 `Characters` | 목록 · 캐릭터 생성(업로드 / AI) · 캐릭터 상세 · 스타일 |

## Character Library 화면

- **목록** — 브랜드/타입별 그룹, 필터(Favorites · Created by · Age · Gender), 이름 변경, 삭제
- **캐릭터 생성** — `Upload images` / `Generate with AI` 두 탭, 레퍼런스 이미지 0–10장 규칙,
  업로드 진행 상태, 프리뷰 생성 → `Choose your favorite`
- **캐릭터 상세** — 소스 이미지 + 스타일 갤러리(Favorites / All styles)
- **스타일 상세** — 우측 패널. 패널이 열리면 갤러리가 4열 → 3열로 밀려나며,
  가려지는 카드가 없습니다
- **New Style** — 선택값이 Generation prompt로 조립되고, `Refine the prompt`로 재작성

## 프로토타입 전용 UI

화면 하단의 `Screens` 버튼과 `SIGNED IN AS` 역할 전환 바는 리뷰용 도구이며 제품 UI가 아닙니다.
역할(Super admin / Multi-brand / Single-brand)에 따라 필터와 그룹 기준이 달라집니다.
